    VPN backups

    Archives are unencrypted and contain VPN private keys. Keep an off-device copy. Restore restarts wg0 and replaces keys, clients and settings; .prev is not a full rollback of /etc/pivpn.

    Backups made with this appliance's pivpn backup command before the web UI are supported. Upload the original .tgz without unpacking or converting it. Restoring a VPN backup does not change your web UI password.

    Uploads keep the original filename and use the upload time as the modified time. A same-named backup is replaced only after validation. Creating a backup retains the newest five archives; uploaded archives are subject to that retention on the next creation.
